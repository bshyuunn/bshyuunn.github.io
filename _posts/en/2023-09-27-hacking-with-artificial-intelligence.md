This is the English version of my Hackingcamp presentation on using reinforcement learning to explore web hacking. The talk introduces the basic ideas behind reinforcement learning, then describes how I modeled a web application as an environment in which an agent could choose actions and receive feedback.

The slides include the experimental setup, a web hacking example, the results, and a short discussion of what did and did not work. They document a 2023 experiment, not a current claim that the method can reliably find vulnerabilities in real-world sites.
